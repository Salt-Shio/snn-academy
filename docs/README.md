# SNN Academy 教學內容撰寫慣例

這裡放的是**學習者看的教材**（VitePress 靜態站），跟 `dev/` 底下給開發者看的數學筆記是兩套文件：
`dev/math/` 可以假設讀者懂程式碼和線性代數，`docs/academy/` 要從直覺講起，兩邊不要混著寫。

## 資料夾結構：topic-first

每個主題一個資料夾：`docs/academy/{topic}/`，資料夾內放這個主題從生物直覺到數學推導的所有頁面，
不拆成跨主題共用的分類層（曾規劃過「生物/電路/數學」三層通用概念頁的鏡頭優先架構，已正式否決，
見 `dev/TODO.md` Phase 8 決策更新）。

目前主題：
- `lif/`：LIF 神經元

資料夾名稱英文 kebab-case、不加數字前綴，**不要**預先比照 `dev/math/` 的機制分類詞（神經元模型／突觸
模型／訊號源／量化指標）建立對應資料夾——那是開發者筆記按「機制種類」分類、一類底下塞多個平行模型
的組織方式；`docs/academy/` 是 topic-first，一個資料夾就是一個有完整敘事的主題，兩套分類邏輯不是同
一回事，硬套會不小心重新做出「共用分類容器」，等於變相復活已否決的鏡頭優先架構。

**新主題 vs 掛在既有主題底下的判斷準則**：如果一個模型只是在既有敘事基礎上多一個自身狀態變數
（例如 ALIF 之於 LIF，多一個適應電流），直接加頁面到既有主題資料夾，不開新主題。只有當一個模型
需要重新鋪陳一套完整「生物直覺 → 電路 → 數學」敘事時，才另開一個頂層主題資料夾，資料夾名稱等
實際規劃該主題內容時再個案決定，不要現在就預先畫好分類容器。

## 新增一篇頁面的步驟

1. 在對應主題資料夾建立 `.md` 檔，檔名英文 kebab-case，不加數字前綴。
2. 打開 `docs/shared/academy-map.ts`：
   - 在 `nodes` 加一個 `AcademyNode`，填 `status: 'content'`、`link`、`sidebar: { topic, text, order }`。
   - 在 `edges` 補上跟前後節點的連線。
3. 打開 `docs/shared/academy-layout.ts`，加一行這個節點的座標 `id: { x, y }`（手動排版，抓相鄰節點的
   座標推算，格式單純只有座標、不摻雜其他欄位，方便之後單獨微調位置）。
4. 如果是全新主題，先在 `academy-map.ts` 的 `topics` 加一筆 `TopicMeta`。
5. 存檔後 sidebar 跟首頁知識樹會自動反映（內容跟座標分成兩份各自單純的資料檔，不用手動同步 sidebar）。

## 內容骨架參考

沒有強制模板，但盡量維持「先給直覺、再給機制、最後給公式」的順序（跟 `dev/math/` 相反，
那邊是先寫方程式）。數學沿用 KaTeX（`$...$`/`$$...$$`），電路圖用手刻 SVG 直接寫在 `.md` 裡。
