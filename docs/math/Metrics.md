# 神經元特性量化指標 (Neuron Metrics)

為了量化神經元的輸入輸出關係以及放電的隨機性，我們引入了兩個核心指標：F-I 曲線與 $CV_{ISI}$。

## 1. F-I 曲線 (Frequency-Intensity Curve)

F-I 曲線描述了神經元的「增益特性」，即輸出放電頻率 $f$ 隨輸入電流 $I$ 變化的函數關係。

### A. 解析解推導 (Mathematical Derivation)

為了推導放電頻率 $f$ 與輸入電流 $I$ 的關係，我們從 LIF 基礎方程出發：
$$\tau_m \frac{dV}{dt} = -(V - V_L) + \frac{I}{g_L}$$

#### 1. 求解穩態電位 $V_\infty$
假設電位不被閾值限制，當 $t \to \infty$ 時電位會趨於穩定。令 $\frac{dV}{dt} = 0$：
$$V_\infty = V_L + \frac{I}{g_L}$$

#### 2. 解膜電壓隨時間的變化 $V(t)$
設定脈衝重置後的初始條件為 $V(0) = V_{reset}$。求解該一階線性微分方程得：
$$V(t) = V_\infty + (V_{reset} - V_\infty) e^{-t/\tau_m}$$

#### 3. 計算到達閾值的時間 $T_{isi}$
令 $V(T_{isi}) = V_{th}$（即電位爬升至閾值的時刻）：
$$V_{th} = V_\infty + (V_{reset} - V_\infty) e^{-T_{isi}/\tau_m}$$
整理後可得：
$$T_{isi} = \tau_m \ln \left( \frac{V_\infty - V_{reset}}{V_\infty - V_{th}} \right)$$

#### 4. 最終頻率公式
考慮到放電後的不應期 $t_{ref}$，一個完整的放電週期為 $T_{total} = t_{ref} + T_{isi}$。頻率 $f$ 即為週期的倒數：
$$f(I) = \frac{1}{t_{ref} + \tau_m \ln \left( \frac{(V_L + I/g_L) - V_{reset}}{(V_L + I/g_L) - V_{th}} \right)}$$
*(註：此公式僅在 $V_\infty > V_{th}$，即 $I > g_L(V_{th} - V_L)$ 時有效。若電流不足以將電位推向閾值，頻率為 0。)*

### B. 數值掃描實作 (Numerical Scan)
在沙盒中，我們不直接套用公式，而是透過「原子模擬」來獲得最真實的特性：
1. **電流走訪**：在指定的區間（如 0 到 800 pA）內，以固定步長（如 10 pA）進行走訪。
2. **獨立模擬**：針對每個電流值，建立一個全新的神經元實例並模擬 1000 ms。
3. **頻率換算**：統計 1 秒內的總脈衝數，該數值即為 Hz。

這種方法的優點是：**即使神經元內部邏輯變得複雜（如加入適應性電流），F-I 曲線仍能準確反映其實際行為。**

## 2. 放電變異係數 ($CV_{ISI}$)

$CV_{ISI}$ (Coefficient of Variation of Inter-Spike Intervals) 是衡量脈衝序列「規律性」的無因次指標。

### A. 定義
假設一系列脈衝時間為 $\{t_1, t_2, ..., t_n\}$，其脈衝間隔 (ISI) 為 $ISI_i = t_{i+1} - t_i$。

$$CV_{ISI} = \frac{\sigma_{ISI}}{\mu_{ISI}}$$

其中：
- $\mu_{ISI}$：脈衝間隔的平均值。
- $\sigma_{ISI}$：脈衝間隔的標準差。

### B. 生理意義
- **$CV_{ISI} \approx 0$ (極規律)**：常見於強大的恆定電流驅動，神經元像時鐘一樣精準放電。
- **$CV_{ISI} \approx 1$ (泊松隨機)**：常見於具有大量隨機突觸輸入的情況（泊松脈衝源），代表放電過程接近無記憶的隨機過程。
- **$CV_{ISI} > 1$ (叢集/爆發性)**：代表脈衝傾向於在短時間內成群出現，隨後有較長的停頓。

透過觀察 $CV_{ISI}$，我們可以量化「背景雜訊 (GWN)」如何破壞神經元的放電規律，並觀察 E/I 平衡對輸出不確定性的貢獻。
