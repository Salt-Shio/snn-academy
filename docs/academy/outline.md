# 學習大綱 (Outline)

歡迎來到 SNN Academy！本課程將帶您深入了解脈衝神經網路 (Spiking Neural Network, SNN) 的核心原理。

我們將以 **LIF (Leaky Integrate-and-Fire)** 神經元模型為起點，從生物學的源頭出發，經過等效電路的轉換，最終推導出精確的微分方程。

## 課程章節

1. **[生物的概念](./lif/biological-concept.md)**
   從生物神經元的視角，了解神經訊號是如何被觸發與傳遞的，並探討膜電位變化的四個階段（極化、去極化、再極化、過極化）。

2. **[等效電路的概念](./lif/circuit-concept.md)**
   將生物細胞膜與離子通道抽象化為電容與電阻，建立神經元的 RC 等效電路模型，並推導出電流恆等式。

3. **[微分方程](./lif/differential-equation.md)**
   深入分析等效電路的動態行為，並進一步簡化，最終建構出乾淨且易於模擬的 LIF 微分方程模型。
