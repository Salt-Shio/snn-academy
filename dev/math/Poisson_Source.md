# 泊松脈衝源 (Poisson Spike Source)

泊松過程 (Poisson Process) 是神經科學中模擬隨機放電活動（如背景雜訊或傳入訊號）最常用的機率模型。

## 1. 物理意義

假設神經元的放電是完全獨立的隨機事件，即：
- 神經元在這一刻是否發射脈衝，與前一刻的狀態完全無關（無記憶性）。
- 在極短時間 $\Delta t$ 內發生一次脈衝的機率與時間長度成正比。

## 2. 發生機率計算

給定平均放電頻率 $r$ (單位：Hz，次/秒)，在一個極小的模擬時間步長 $\Delta t$ (單位：ms) 內，發生一次脈衝的機率 $P$ 為：

$$P = r \times \frac{\Delta t}{1000}$$

其中 $\frac{\Delta t}{1000}$ 將毫秒換算為秒。

## 3. 程式碼實作 (`PoissonSource.ts`)

在每個 `step(dt)` 呼叫時，我們產生一個介於 0 到 1 之間的均勻分佈隨機數。如果該隨機數小於計算出的機率 $P$，則觸發脈衝：

```typescript
const probability = this.rate * (dt / 1000);
if (Math.random() < probability) {
  this.hasSpiked = true;
}
```

## 4. 變異數與均值 (性質)

對於理想的泊松過程，其脈衝數量的均值與變異數相等。在視覺化沙盒中，你會發現當 $r$ (Hz) 增加時，輸入脈衝序列會變得更加密集且混亂，進而推動 LIF 神經元更頻繁地跨越閾值。
