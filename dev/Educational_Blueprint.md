# SNN 視覺化學習路徑藍圖 (Educational Blueprint)

為了讓學習者能直觀地理解脈衝神經網路 (SNN) 的底層運作邏輯，本專案的 UI 與互動體驗將從「純參數沙盒」轉型為「三階段引導式學習」。

學習路徑將遵循：**生物直覺 $\to$ 電路邏輯 $\to$ 數學抽象**。

---

## 階段一：生物學視角 (Biological Perspective)
**目標**：建立對神經元通訊最直觀的視覺認知，理解「化學訊號如何轉為電訊號」。

*   **巨觀視覺**：畫面呈現多個前級神經元（Pre-synaptic）連接到單一後級神經元（Post-synaptic）的動態網路圖。
*   **互動設計**：
    *   **觸發**：使用者可以點擊前級神經元來手動發射脈衝 (Spike)。
    *   **放大轉場 (Zoom-In)**：突觸節點設計為「可點擊」。點擊後，畫面放大進入突觸間隙 (Synaptic Cleft) 的微觀視角。
*   **微觀動畫展現**：
    1.  **訊號抵達**：動作電位傳遞至突觸末梢。
    2.  **化學釋放**：神經傳導物質（如 Glutamate）從囊泡釋放。
    3.  **受體結合與離子流動**：傳導物質結合到後膜受體，離子通道打開，展示帶正電的離子（如 $Na^+$）流入細胞內。
    4.  **電位累積**：視覺化呈現細胞內部正電荷的增加，以及這如何促使神經元本體最終觸發其自身的動作電位。

---

## 階段二：電路學視角 (Circuit Equivalent Perspective)
**目標**：將生物學的「離子流動與細胞膜」抽象化為工程學的「等效電路 (Equivalent Circuit)」。

*   **視覺轉換**：透過動畫，將階段一的生物結構逐漸淡化，疊加上電子電路元件的符號。
*   **核心對應邏輯**：
    *   **細胞膜 (Lipid Bilayer) $\to$ 電容 ($C_m$)**：解釋細胞膜如何像絕緣體一樣阻擋電荷，使細胞內外形成電位差（儲存電荷）。
    *   **離子通道 (Ion Channels) $\to$ 可變電阻 / 電導 ($g_L, g_{syn}$)**：解釋離子的流通阻力。突觸通道開啟，等於電阻下降（電導上升），電流得以通過。
    *   **濃度梯度 (Concentration Gradient) $\to$ 電池 ($E_L, E_{rev}$)**：解釋細胞內外離子濃度差如何提供驅動電荷流動的「電動勢」。
*   **動態展示**：當前級脈衝抵達時，展示開關（突觸通道）閉合，電流 $I_{syn}$ 流入並對電容 $C_m$ 進行充電，導致電路中的電壓 (膜電位) 逐漸升高的過程。

## 階段三：數學與模型視角 (Mathematical Formulation)
**目標**：從電路的基爾霍夫定律 (Kirchhoff's Laws) 順理成章地推導出 Leaky Integrate-and-Fire (LIF) 的微分方程。

*   **視覺關聯**：畫面上半部保留 RC 電路圖，下半部呈現互動式的數學公式與即時波形圖。
*   **核心公式推演**：
    *   根據電流守恆：流入電容的電流 = 總輸入電流 - 漏電流。
    *   展示公式：$C_m \frac{dV}{dt} = -g_L(V - V_L) + I_{syn}$。
*   **互動學習 (Math-UI Mapping)**：
    *   **參數連動**：提供滑桿調整 $C_m, g_L$ 等參數。滑動時，公式內的數值即時改變，右上角的電路圖元件跟著變形（例如電容符號變大），同時下方的膜電位 ($V$) 動態波形圖（如 F-I 曲線或充電曲線）也即時反應變化。
    *   **閾值與重置**：在圖表上明確標示閾值 $V_{th}$。當電壓軌跡碰到該線時，觸發 Spike 動畫並將電壓強制拉回 $V_{reset}$。

## 實作規劃建議 (Implementation Roadmap)

1.  **UI 佈局重構**：將現有的單一 Dashboard 拆分為三個主要的導覽分頁（Tabs/Routes）：`[生物視角]`, `[電路視角]`, `[數學模型]`。
2.  **2D/3D 動畫引入**：階段一與階段二需要依賴強大的動畫支援。可評估使用 SVG 動畫、Canvas (如 D3.js 甚至 PixiJS) 或 CSS 轉場來實作平滑的「細胞轉電路」過渡。
3.  **逐步釋出**：
    *   **v1.0**: 先完善「階段三 (數學與互動圖表)」的 UI 連動，這是目前沙盒已經有基礎的部分。
    *   **v2.0**: 補上「階段二 (RC 電路)」，實作靜態或輕量動態的電路圖與參數的綁定。
    *   **v3.0**: 實作最複雜的「階段一 (生物微觀動畫)」，並串聯完整的轉場體驗。
